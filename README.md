# Loan Management System

# Project Description

Loan Management System is a simple and user-friendly application developed using Python, Tkinter, and Excel. It is designed to manage loan records efficiently.

# Technologies Used

- Python
- Tkinter
- Excel
- OpenPyXL

# Features

- Login Validation
- Dashboard
- Add Loan
- View Records
- Search
- Update
- Delete
- EMI Calculation
- Clear
- Logout

# Project Objective

The main objective of this project is to provide a simple and user-friendly system for managing loan records.

# Working

The user first logs into the system using valid credentials. After successful login, the dashboard is displayed. The user can add new loan records, view existing records, search for records, update details and delete records. EMI can also be calculated based on the loan amount, interest rate and tenure. All loan records are stored and managed in an Excel file.

# How to Run

1. Install Python.
2. Install OpenPyXL:
   pip install openpyxl
3. Open the project in VS Code.
4. Run the Python file.
5. Login and use the Loan Management System.
